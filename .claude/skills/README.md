# Skille Embargo (marketing)

Skille projektowe Claude Code — ładują się automatycznie, gdy sesja działa w tym repozytorium.
Każdy folder zawiera `SKILL.md` oraz opcjonalnie `reference/` (wiedza o marce) i `scripts/` (walidatory).

| Skill | Do czego |
|---|---|
| `check-embargo-brand-voice` | Sprawdzanie tonu marki i claimów |
| `localize-embargo-ads` | Transkreacja UK ↔ PL (docelowo ES) |
| `write-embargo-meta-ads` | Copy reklam Meta (FB/IG) |
| `write-embargo-google-ads` | RSA i zasoby Google Ads |
| `write-embargo-competitor-ads` | Reklamy porównawcze / conquest |
| `write-embargo-video-scripts` | Skrypty wideo, UGC, testimoniale |
| `brief-embargo-static-ads` | Koncepcje i briefy statyk |
| `build-embargo-pmax-assets` | Grupy zasobów Performance Max |
| `build-embargo-lead-magnet-funnel` | Lejki lead magnetów + nurturing |
| `adapt-embargo-ads-linkedin-tiktok` | Adaptacja na LinkedIn i TikTok |
| `audit-embargo-landing-page` | Audyt LP, message match, CRO |
| `plan-embargo-keywords` | Słowa kluczowe, wykluczenia, search terms |
| `plan-embargo-creative-tests` | Plan i rejestr testów kreacji |
| `review-embargo-ad-performance` | Analiza wyników i raporty PPC |

`reference/embargo-essentials.md` jest powielony w kilku skillach — przy zmianie zaktualizuj wszystkie kopie.
